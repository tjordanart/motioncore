# MotionCore

**Personal Project**

A Java-based 2D animation editor featuring keyframes, timeline controls, and real-time animation playback.

**Status:** In Development

## Overview

MotionCore is a personal project that combines my background in motion graphics and animation with my studies in computer engineering. The goal is to build an animation editor from the ground up while developing software engineering skills through hands-on development.

The project focuses on keyframe-based animation, interactive editing tools, and the relationship between objects, timelines, and animation playback.

## Features

- Keyframe-based animation with linear interpolation
- Multiple animated objects
- Real-time animation playback
- Play and pause controls
- Timeline scrubbing
- Selectable and draggable canvas objects
- Add Keyframe functionality
- Draggable timeline keyframes for adjusting animation timing
- Circle and square animations
- Interactive timeline and canvas

## How to Run

Clone the repository:

```bash
git clone https://github.com/tjordanart/motioncore.git
```

Open the project in Eclipse or another compatible Java IDE and run `Main.java`.

No external libraries are currently required.

## Project Goals

MotionCore is an opportunity to apply software development concepts to a practical creative application. By building an animation editor, I can combine my professional experience in animation with hands-on programming, interface development, and application architecture.

The long-term goal is to create a flexible 2D animation tool with an interactive timeline, advanced keyframe controls, and expanded animation capabilities.
