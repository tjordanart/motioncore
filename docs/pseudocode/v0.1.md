# MotionCore V0.1 - Basic Keyframe Interpolation

## Goal

Create a basic animation system that calculates the position of an object
between two keyframes.

## Inputs

- Starting X position
- Starting Y position
- Ending X position
- Ending Y position
- Starting time
- Ending time
- Current time

## Process

START

Create starting keyframe
Create ending keyframe

Set the current time

Calculate the total animation duration

Calculate the progress between the starting and ending keyframe

Calculate the current X position

Calculate the current Y position

Display the current position

END

## Example

Starting Keyframe:
Time = 0 seconds
Position = (100, 300)

Ending Keyframe:
Time = 2 seconds
Position = (700, 300)

At 1 second:

Progress = 50%

Current Position = (400, 300)
