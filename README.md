# MotionCore

**A Java-based 2D animation engine and interactive animation editor built from scratch.**

> **Status: Work in Progress — Early Development**

## Overview

MotionCore is a personal project combining my background in motion graphics and animation with my studies in computer engineering. The goal is to build an animation editor from the ground up while developing my software engineering skills.

## Current Progress

- [x] Keyframe-based animation and linear interpolation
- [x] Multiple animated objects
- [x] Play/pause controls and timeline scrubbing
- [x] Selectable and draggable canvas objects
- [x] Add Keyframe functionality
- [x] Draggable timeline keyframes for adjusting timing
- [ ] Individual keyframe position editing

## Features

- Circle and square animations
- Multiple keyframes per animation
- Interactive timeline
- Real-time animation playback
- Object selection and manipulation

## Planned Features

- Position, rotation, scale, and opacity controls
- Improved layer and timeline editing
- Animation paths
- Physics-based animation
- Save and load animation projects

## Technology

- Java 17+
- Java Swing
- Object-oriented programming
- Event-driven programming
- Keyframe interpolation

## How to Run

Clone the repository:

```bash
git clone https://github.com/tjordanart/motioncore.git
```

Open the project in Eclipse or another compatible Java IDE and run `Main.java`.

No external libraries are currently required.
